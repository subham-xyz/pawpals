Questions

Frequently asked questions

Is PawPals free?

Yes. It is a community network run by volunteers.

How are volunteers verified?

An admin checks each new volunteer profile before it becomes visible or can be matched.

Can I get medical help for my pet here?

No. PawPals is only for non-medical help. Please contact a registered vet for health issues.
